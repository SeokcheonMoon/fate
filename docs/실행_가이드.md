# FATE 실행 가이드

FATE 페이지를 실행할 때는 아래 순서만 따르면 됩니다. KRX가 당일 데이터를 아직 제공하지 않는 경우에도 마지막 적재 거래일 기준으로 예측 CSV가 생성됩니다.

## 1. 가상환경 활성화

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
cd C:\Develops\fate
.\.venv\Scripts\Activate.ps1
```

## 2. 일일 데이터 갱신과 예측 CSV 생성

```powershell
python -m etl.daily_prediction_update
```

이 명령은 다음 작업을 순서대로 수행합니다.

1. KRX 종목 기본정보 갱신
2. KOSPI 종목별 일별 시세 증분 적재
3. KOSPI 지수 증분 적재
4. 최종 모델로 종목별 다음 거래일 상승확률 생성

생성 파일:

- `data/predictions/latest_direction_predictions.csv`: 예측 가능한 전체 종목
- `data/predictions/kospi_top20_predictions.csv`: 상승확률 상위 20개 종목
- `data/predictions/prediction_history.csv`: 기준일별 예측 이력

## 3. Streamlit 대시보드 실행

```powershell
streamlit run dashboard/app.py
```

브라우저가 자동으로 열리지 않으면, 터미널에 출력되는 `Local URL` 주소를 브라우저에서 열면 됩니다.

대시보드를 종료하려면 실행 중인 터미널에서 `Ctrl + C`를 누릅니다.

## 데이터·모델을 처음부터 다시 만들 때만 실행

일상적인 페이지 실행에는 필요하지 않습니다.

```powershell
# OHLCV 패널, EDA, CDA 재생성
python -m analysis.ohlcv_eda

# KOSPI 시장 피처 결합 워크포워드 검증
python -m ml.kospi_market_walk_forward

# Logistic Regression 간결 피처 모델 선택
python -m ml.kospi_market_model_selection

# Logistic Regression · Random Forest · XGBoost · LightGBM 최종 홀드아웃 비교
python -m ml.kospi_market_holdout_benchmark
```

최종 모델은 `ml/models/final_kospi_direction_model.joblib`에 저장됩니다. 모델을 다시 학습한 뒤에는 `python -m ml.kospi_daily_prediction`을 실행해 예측 CSV를 새로 만듭니다.
