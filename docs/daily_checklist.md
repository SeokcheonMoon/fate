## 9/2 작업 기록 — 3년 OHLCV 백필, 복구 설계, 시간순 예측 검증

### 1. 과거 데이터 적재 범위 확장

- KRX Open API 기반 KOSPI 일별 OHLCV 적재 범위를 `2023-09-01 ~ 2026-08-28`로 확장
- 최종 분석 패널: 944종목, 675,189건
- 데이터 품질 검증 결과: 종목·날짜 중복 0건, OHLCV 결측 0건

### 2. 백필 중단 원인 분석과 복구

- 3년치 적재 중 2024-06-06 부근에서 KRX가 JSON이 아닌 응답을 반환해 적재가 중단됨
- 일일 API 한도 10,000회 대비 날짜 단위 약 780회 요청이므로 한도 소진 가능성은 낮았고, 동일 인증키·엔드포인트를 즉시 재확인해 정상 HTTP 200 및 944개 종목 응답을 확인
- 이에 따라 인증키 만료나 영구 차단이 아니라 일시적인 응답 제한 또는 호출 부담으로 판단
- 데이터를 삭제하거나 처음부터 다시 적재하지 않고 아래와 같이 복구 가능하도록 개선
  - 요청 간격 0.35초 적용
  - 일시 오류에 최대 5회 지수 백오프 재시도 적용
  - 실패 날짜를 ETL 로그에 남겨 원인 추적 가능하게 구성
  - 성공·빈 응답 처리 날짜를 ETL 이력으로 판별해 동일 명령 재실행 시 미적재 날짜만 재개
  - 전체 기간을 의도적으로 다시 적재해야 할 때만 `--force` 사용

### 3. EDA·CDA 재실행

- `python -m analysis.ohlcv_eda` 실행 완료
- RSI(14), MACD, 종가 변화율, 거래량 변화율, 거래량 비율, 장중 변동성, 이동평균 괴리율을 생성하고 한국어 레이블 시각화 생성
- 일별 횡단면 스피어만 IC, HAC(Newey-West) 표준오차, Benjamini-Hochberg FDR 5% 보정으로 다음 거래일 수익률과의 관계 검정
- 장중 변동성(-0.0621), 5일 이동평균 괴리율(-0.0419), 전일 종가 변화율(-0.0398), 20일 이동평균 괴리율(-0.0355), RSI(-0.0261), MACD(-0.0188)는 유의한 음의 관계 확인
- 거래량 변화율(+0.0052)은 약하지만 유의한 양의 관계 확인, 20일 평균 대비 거래량은 유의하지 않음

### 4. 다음 거래일 상승 여부 기준 모델 및 시간순 검증

- 초기 6개월 학습 후 한 달씩 앞으로 이동하는 확장 윈도우 방식으로 검증해 미래 정보 누출 방지
