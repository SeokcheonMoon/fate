### 4. 최종 모델과 해석 기준

- 최종 모델: `ml/models/final_kospi_direction_model.joblib`

- 로지스틱 회귀만 사용한 최종 선택의 한계를 점검하기 위해 동일한 간결 시장 결합 피처로 Random Forest, XGBoost, LightGBM을 추가 비교
- 2026-03-03 ~ 2026-08-28의 111,927건을 미사용 최종 홀드아웃으로 고정하고, 이전 532,751건으로 각 모델 학습
- 최종 홀드아웃 결과

| 모델 | 정확도 | ROC-AUC | 상위 20% 상승률 개선 |
|---|---:|---:|---:|
| Logistic Regression | 47.9% | **0.5800** | **+10.90%p** |
| XGBoost | 55.1% | 0.5660 | +6.32%p |
| LightGBM | 54.6% | 0.5443 | +3.76%p |
| Random Forest | 55.4% | 0.5241 | +6.53%p |

- Logistic Regression이 ROC-AUC와 상위 20% 선별력에서 모두 가장 높아 최종 모델로 확정
- 정확도는 클래스 균형 처리 및 0.5 임계값의 영향을 받으므로, 모든 종목의 방향 정확도보다 상승확률 순위 품질을 우선해 해석
- 홀드아웃 비교 후 선택된 Logistic Regression은 전체 이용 가능 기간으로 재학습해 `ml/models/final_kospi_direction_model.joblib`에 저장
